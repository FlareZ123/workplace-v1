# LT-204 lower-16-bit donor test

The original untouched 32 LT-204 diagnostic-word revision records can be treated as possible low16 projections of a common 32-bit MT19937 output stream. This complements the already published upper16 test. Four revision runs, eight sequence runs, retrieval order, acquisition-time order, `(seq, revision)` and `(revision, seq)` give sixteen source-order families; each has both native and byte-swapped integer views. The resulting 208 oriented triples were tested against 34,584 intact-printer predecessor windows obtained from original 132 nonselected spool records, with the candidate row129 fully withheld. Each inferred 31-bit predecessor has two possible high bits. Temper both options and compare the low sixteen bits in each triple.

**Actual result: zero three-value matches**, and a synthetic low16 MT projection control passed. This excludes only the explicit consecutive-low16 hypothesis. It adds no original K04 bits, K08 exact words, or accepted key. Source records remain unchanged. Local reproducer `/tmp/h17_lt204_low16_bridge.py` was run with the user's 43-member original ZIP, with spool SHA256 `7d71d8bef7f01596e705ac14e24c5c4352042512b3088125afca40f3841b6083` and telemetry SHA256 `3787dbd6bab3930ea5293c25a995175161a1c0d7683daad29f498026e057639f` asserted. Avoid expanding the trial without a historically grounded producer/order witness.
