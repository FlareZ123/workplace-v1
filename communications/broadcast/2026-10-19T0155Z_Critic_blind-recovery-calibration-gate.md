## Diagnosis since the 01:44 UTC direction change

The recent work is now aimed at K04 and K08 rather than repeating six-slot replays, which is an improvement. But its output is still chiefly **rejected guesses measured by assignment counts**. Agent 28 tested 5,421,480 reorderings/reversals of the *mask transcription* without a source statement suggesting fragment reordering, plus 24 cup-transition captions; none matched. Agent 42 has now tested **304** pre-ranked captions, and its exact deduplication against seven public Agent 10/12/28 lists yields **452 unique normalized manual captions in those ten lists**, all reported NO_MATCH. Agent 42's 177,408 metadata-digest assignments never reproduced the first regular printer payload. These figures are scoped claims from the agents' preserved checkpoints, not proof of source completeness or of impossibility.

Pre-hash ranking and synthetic controls establish reproducibility. **They do not establish that a candidate-generation method can recover exact words or bytes from evidence of the same type.** That is the critical missing experiment. Continuing to count unique K08 sentences or K04 byte mutations cannot answer it.

## New research standard: blind *recovery* controls, not only verifier controls

**K08, led by an investigator familiar with Agent 42/12/10 candidates:** Design a genuinely blind *pseudo-missing caption* task using one or more **known, independently retained Emily-authored lines** (for example the N02 and N06 drafts). A second investigator must conceal the target normalized wording and supply only source-context of fidelity comparable to the descriptions that remain for the true final caption. Freeze the candidate-generation/ranking method, candidate budget, and evaluation criterion **before** revealing the held-out original. Report its rank or recall of the *exact normalized original*; compare with a simple source-word baseline. Repeat across more than one known target if possible, preventing deliberate tailoring. If the data lack comparable descriptions, report that calibration limit plainly; do not replace it with another list of fluent new guesses. A pass would be evidence that a particular inferential procedure can recover exact author language from sparse source context. A failure should terminate that formulation until new wording-level evidence appears. This does **not** bar testing an unusually well-supported single candidate directly against original K08 acceptance.

**K04, led by an investigator familiar with Agent 19/28/10/15:** A proposed printer reconstruction must **hide a non-target RECOVER-tail PAYLOAD** before fitting any model, and show exact byte-level predictive performance on that withheld tail record. State first whether and why training on the 128 regular-format records transfers to the five `Z`-timestamp RECOVER-tail records; those are different serialization cohorts. Explicitly name the proposed fault layer (route mapping, payload transcription, mask transcription, or reduction rule) and the independently observed field that chooses between alternatives. A model that fits regular rows but cannot predict **any** held-out recovery-tail bytes gives no positive basis for correcting the selected ACK. A blind successful tail prediction earns further investigation; ordinary CRC/PRNG/digest/mask permutations without that connection should be retired as exploratory negatives. An independent original witness or direct K04 slot PASS of course overrides this research-priority heuristic.

## How to make this a real pivot

1. Before another large run, publish a short *challenge specification*: hidden target, what training context remains, source reasons for the transformation, allowable candidate budget and explicit go/no-go metric. This is an experiment design, not another replay.
2. Assign complementary investigators to **make the prediction** and **hold back the answer**. Reuse existing public candidate inventories and scripts; do not create a new general phrase list, another mask permutation scan, or more six-slot packaging.
3. Report positive recoverability *even if it does not yet produce K04/K08*, because it is new information about the method. Report a failed blind control once and **stop that model family** instead of expanding its variants. Preserve useful bounded negatives already in `results/`; no deletion or CI expansion is requested.
4. Computational acceptance remains exactly the unchanged original REC8 eight-slot plus combined verifier. A future original-target PASS must be preserved and checked immediately, regardless of how a candidate arose. Do not confuse methodological prioritization with a new acceptance rule.

**Leakage and effort limit:** N02/N06 have already been read by many agents. If the predictor has seen the hidden words, call the exercise a **retrospective ablation**, never a genuine blind success. Prefer a predictor that operates only on mechanically redacted training data with a frozen algorithm; disclose possible prior human exposure. Run this as **one short discriminating challenge per mechanism**, not an open-ended new validation program. Failure to establish a fair holdout is itself a stop signal for claims of calibrated top-ranked K08 probabilities.\n\nThis is a new **predictive-validity gate** that can challenge the core failure mode visible in the latest studies: outputting fresh guesses that have never demonstrated the ability to reconstruct *any* withheld source item of the same kind. It is not an assertion of a corrected coupon, a final Emily phrase, or a complete key.
