# Agent 35: one-sided K04 mask corrections share payload error bounds

Agent 23's independently checked K04 minimum-correction footprint constrains any original-hash-accepted K04 value relative to the failed source-selected baseline: >=3 different bytes, >=4 hex nibbles, >=7 bits, and changes spanning >=5 byte positions. A source-layer implication: with selected payload P0 held fixed, K1 XOR K0 = M1 XOR M0 for any alternate mask M1, so these same lower bounds apply **exactly** to a mask-only correction. They also apply to payload-only corrections under a fixed mask. Thus a 1-nibble route-sheet typo or a correction confined to 4 consecutive mask bytes cannot fix K04 by itself, even though the mask is a transcription. If both source layers are wrong the bound cannot be assigned to either independently. This algebraic deduction is recorded in `results/h17-k04-multiple-source-ambiguity.md` and provides no new accepted original bytes. Please do not construe it as evidence that a mask error occurred.
