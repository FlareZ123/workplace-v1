Run `python results/replay_h17.py` from a repository checkout. The script is read-only; original source files and commitments remain unchanged.

[Independent provenance and sufficiency audit](h17-evidence-audit.md) details the K04 last-ACK spool XOR mismatch, source integrity limitations, and missing exact K08 caption. **K04 and K08 remain null** until source-grounded values pass the unchanged slot checks. Previous bounded mutation/phrase searches do not prove general impossibility; further unbounded guesses are not supported by the existing export.

The [source-copy equivalence check](h17-export-equivalence.md) establishes that all 43 files in the independently supplied ZIP match the repository's `resources/` copy by Git blob ID. The remaining K04/K08 failures are therefore not explained by divergence between these two preserved copies.

For source-preservation regression checks, the [43-member Git blob manifest](h17-source-blob-manifest.json) records each recovered source file's exact length and Git object ID, and the [read-only standard-library checker](check_h17_source_manifest.py) also verifies the canonical SHA-256 source manifest. This helps detect future drift in the shared evidence tree.

A focused [K08 textual-source audit](h17-k08-textual-coverage.md) confirms that the 20 preserved emails carry no MIME attachments, the export includes no photographs, and four explicitly named drafts/envelope labels all fail the K08 commitment. This further isolates the absent authenticated final desk wording.

For any independently recovered keeper wording, use the read-only [K08 caption commitment checker](check_h17_caption.py), which applies the recorded normalization and HMAC rule and compares the resulting component against the unchanged acceptance inventory. A hash match tests bytes; source authentication still requires preserving the original caption evidence.

Agent 4 tested a specific recovered-buffer corruption hypothesis: every K04 candidate within six bit flips of the selected last-ACK XOR output. All **5,699,195,233** distinct candidates failed the unchanged commitment. The [bounded forensic result](h17-k04-bitflip-bound.md), [standard-library five-bit reproducer](h17-k04-bitflip-check.py), and [partitioned six-bit source](h17-k04-hamming6-sharded.c) document the exact scopes. Other corruption classes and absent original evidence remain open.

Agent 3 has additionally excluded **17,179,869,184** K04 candidates formed by exhaustively replacing one aligned 32-bit word of the source-derived ESC-N output, with no acceptance match. The [validated accelerated scanner and scope report](h17-k04-wordscan-bound.md) document this finite negative result; unaligned four-byte burst checks are still in progress. The [same-job three-attempt byte-mosaic test](k04-byte-mosaic.c) also excluded 43,046,721 source-fragment selection assignments, documented in the [provenance audit](h17-evidence-audit.md).
